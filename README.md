# benthedev

The apps behind benthedev.com, one folder each under `apps/`:

- `apps/colony-planner`: the colony campaign planner and Beny Bot, at colony.benthedev.com
- `apps/about-me`: the personal site, at benthedev.com

Tools are pinned with [mise](https://mise.jdx.dev). Run an app's tasks from its folder (`mise run check`)
or from anywhere with `mise run //apps/<app>:<task>`. Each app's own README or CLAUDE.md says how to set
it up.
