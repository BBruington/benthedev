# M0 checklist: sign-in, approval, shell

## Start it

1. Make sure Docker Desktop is running.
2. In Terminal:

   ```bash
   cd ~/myCodeSpace/benthedev/apps/colony-planner
   mise install
   mise run fresh
   mise run dev
   ```

   `fresh` wipes the local database and loads the sample campaign. Wait for `dev: open http://localhost:5173`, and leave that tab open.

## Try it

A private browser window counts as a second person.

1. **Sign-in page.** Open http://localhost:5173. You see the sign-in page over the darkened Eldari map, with a **Dev sign-in** list on the right. The Discord button is replaced by a note until Beny Bot Dev is set up.
2. **You as DM.** Click **Sample DM**. You land on the Colony page ("Sample Colony"). Players and Settings are in the sidebar, or under **More** on a phone.
3. **A new player asks to join.**
   - In a private window, type **Ash** under "A new player asking to join" and click **Ask**. Ash sees "Waiting for the DM to let you in".
   - In your DM window, open **Players**. Ash is already there without a refresh.
   - Click **Let in**. Ash's window opens to the Colony page by itself.
4. **Remove and re-admit.**
   - On Players, open the ⋮ menu next to Ash and choose **Remove from the campaign…**. Ash's window drops to the sign-in page at once.
   - Signing in as Ash again shows "You don't have access".
   - **Players → Removed → Re-admit** lets Ash back in.
5. **Deny.** Sign in as **Emil** in a private window, then click **Deny** next to Emil in your DM window. Emil's window changes to "You don't have access" without a refresh. Only Re-admit lets him in.
6. **Players can't reach DM pages.** Sign in as **Ana (Thorin)** in a private window. Players and Settings aren't in her navigation, and typing `/players` shows a not-allowed page.
7. **View as player.** As DM, click your initials and turn on **View as player**. A banner appears, and DM pages are blocked. Turn it off from the same menu.
8. **Settings.** Change the campaign name and time zone, then save. Reloading keeps the change. Typing letters into a Discord channel field shows an error under that field.
9. **Sign out.** Use the profile menu's **Sign out**. **Sign out everywhere…** asks for confirmation first.
10. **Checks.** In a second Terminal tab, run `mise run check`. It ends with "All checks passed" after a few minutes.

## Optional: real Discord sign-in and Beny Bot

To try these, follow [discord-dev-setup.md](../discord-dev-setup.md) to create a **Beny Bot Dev** test app in a private test server (about 15 minutes). Never use the real Beny Bot's token.

11. **Sign-in and the join ping.**
    - Sign in with Discord: you land as DM.
    - Set your DM channel in Settings.
    - Sign in with a second Discord account in a private window. Beny Bot Dev posts "… is waiting to join" in that channel.
12. **`/beny`.** In the test server, `/beny` answers "Boy!", visible only to you.

## When you're done

- Press Control-C in the `mise run dev` tab.
- `mise run db:down` stops Postgres. Your data is kept.
