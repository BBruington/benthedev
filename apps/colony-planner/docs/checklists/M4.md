# M4 checklist: world maps

## Start it

1. Make sure Docker Desktop is running. If `mise run dev` is running, press Control-C in its tab. The server has to restart to pick up M4.
2. **The next command erases your local data.** It rebuilds the database and loads the new sample data: Sample Colony's Mainland (the Eldari art, uploaded the way a DM uploads it) with the sample places pinned, and a small charted area on the hex map with a few labels. M4 adds web packages (Leaflet), so run `mise run setup` first; it keeps your `.env`.

   ```bash
   cd ~/myCodeSpace/benthedev/apps/colony-planner
   mise run setup
   mise run fresh
   mise run dev
   ```

   Wait for `dev: open http://localhost:5173`. The first start after new packages can stop while Vite re-bundles the web code. If a page doesn't load (Explore or Mainland especially), press Control-C and run `mise run dev` once more.

The steps build on each other, so do them in order. A private window counts as a second person; to switch who is signed in there, sign out and use **Dev sign-in** again.

## Try it

1. **What the sample has.** Sign in as **Sample DM** and open Sample Colony.
   - **Explore**: "19 hexes charted." A patch of plains, water, forest, swamp and one mountain, inside a ring of dashed outlines two hexes deep (the frontier). Zoom in with + (or pinch on a trackpad): the labels **Port Eldari**, **Saltmarsh**, **Wolf Den** and **Grey Tor** appear once the hexes are big enough. Each terrain has a pattern as well as a colour.
   - **Mainland**: one card, **Eldari**, marked Mainland, with **Mainland** and **Visible to players** both on. Open it: the Eldari art fills the frame with five pins: **Port Eldari Docks**, **The Longhouse**, **Saltmarsh Fields**, **Wolf Den Hollow** and **The Drowned Chapel**. "Places on this map" under it lists the same five.
   - Tap a pin: a sheet shows the place's opening lines and **Open Port Eldari Docks** (or whichever you tapped).
2. **A player sees the same, minus the hidden.** In a private window, sign in as **Ana** and open Sample Colony (she is Thorin).
   - **Mainland** → **Eldari** shows **four** pins: no Drowned Chapel (it's a hidden place). No Edit pins, Replace art or Rename.
   - **Places** → **Port Eldari Docks** has an **On the map** section with the art, its pin and **Open Eldari**.
   - **Explore** shows the same 19 hexes and labels as yours.
3. **Painting, labels and Unchart** (Ana's window, at Mac size).
   - Tap the brush button at the bottom right of the map (or press **P**): the pill at the top says "Painting Forest · two fingers move the map". Pick **Water** in the chip bar (or press **3**) and click a few dashed frontier hexes, then drag across several: each hex fills as the pointer passes, with no gaps. "N hexes charted." goes up, and the dashed ring moves outward: **painting at the frontier makes the map grow**.
   - Your window shows Ana's strokes within about 2 seconds, without a reload.
   - Press **P** again to go back to Look. Click the **Port Eldari** hex: a sheet shows "Hex 0, 0", its terrain and the label. Close it. Press **P**, pick **Mountain** (press **4**), click Port Eldari, press **P**, and click it again: its terrain is Mountain and the label is still **Port Eldari**. **Repainting keeps the label.**
   - In the same sheet change the label to "The Landing" and **Save label**. Your window shows the new label.
   - Press **E** (Unchart) in Paint mode and click one of the hexes Ana painted: it goes back to a dashed outline and the count drops by 1.
   - **Find** → type "wolf": **Wolf Den** is listed; tap it and the map zooms to that hex. **Fit** shows everything charted.
   - The **+** and **−** buttons are big, thumb-sized and match the theme. Switch the theme (light to dark) from the profile menu: the dashed frontier and a selected hex's outline change colour at once, without moving the map.
4. **Two players at the same moment.** Sign in as **Hollis** in a second private window (Firefox, or another Chrome profile; he plays Pell here) and open **Explore** in both player windows side by side. Paint a stroke in each at the same time, in different places: after a second or two both windows, and yours, show both strokes.
5. **On your phone: the two-finger split** (decided 2026-10-12). Press Control-C in the `mise run dev` tab and run `mise run dev:phone` instead. On a phone on the same Wi-Fi, open the address it prints, use **Dev sign-in** as **Ana**, and open **Explore**.
   - In Look mode: one finger pans, pinch zooms, and a tap on a hex opens its sheet.
   - Tap the brush button. Pick **Forest** and drag one finger across the frontier: a forest stroke appears under your finger as you go, and the page doesn't scroll.
   - Still in Paint mode, put **two fingers** down and move them together: the map pans. Spread and pinch them: the map zooms. Lift: **no stray hex** where the fingers first landed. Then one finger paints again.
   - Tap the brush button to go back to Look, tap a hex and give it a label.
   - The Mac's player window (Ana's or Hollis's) shows the stroke and the label within about 2 seconds.
   - If two fingers don't pan or pinch in Paint mode, or one finger scrolls the page instead of painting, that's the bug this step is here to find: note the phone and browser.
6. **Pins and a bigger copy of the art** (your window). Make a larger copy of Eldari first, in a Terminal tab:

   ```bash
   sips -s format jpeg -z 1620 2880 ~/myCodeSpace/benthedev/apps/colony-planner/web/public/eldari.webp --out ~/Desktop/eldari-large.jpg
   ```

   - Open **Mainland** → **Eldari** → **Edit pins**. Drag **Wolf Den Hollow** to a new spot; it stays where you dropped it. Tap **The Longhouse** pin and **Remove pin**: it leaves the map and the list under it. Tap an empty spot on the art, and in "Pin a place here" choose **The Longhouse**: it's back, where you tapped.
   - **Replace art** → choose `~/Desktop/eldari-large.jpg`. The art is now 2880 × 1620 and **every pin is in the same spot on the art** as before, including the one you dragged. Ana's window shows the new art and the same pins after a moment.
   - Try **Replace art** with any `.svg` file, or a file over 5 MB: it's refused with a message before anything changes. A picture wider or taller than 16,384 pixels (or over 50 megapixels) is refused too, so no player's phone is asked to open it.
7. **A hidden map.** Back on **Maps**, **Add a map**: name it "The Sunken Isles", choose any picture, turn **Visible to players** off, and save. It opens; pin **The Longhouse** on it with Edit pins.
   - Turn on **View as player** (top bar): **Maps** lists only Eldari, Eldari has no Longhouse pin any more (its pin is on the hidden map now), and **Places** → **The Longhouse** shows no "On the map" section. Copy the hidden map's address into Ana's window: "No such map". Turn **View as player** off.
   - On the card, turn **Visible to players** on: Ana's Maps shows The Sunken Isles with the Longhouse pin, without a reload. Turn it off again.
   - Use **Move up** on its card, then **Delete** it: The Longhouse stays, unpinned.
8. **A portrait.** Open **NPCs** → **Lady Vex** → edit. Under **Portrait**, **Upload portrait** and choose any picture: it saves at once (before **Save**) and shows on her page and the roster. Ana's **NPCs** shows it too. Give a hidden NPC (Mother Corrow) a portrait: it never appears in Ana's window.
9. **Your own Mainland in a fresh campaign** (C6: Eldari is never offered to other campaigns). In the private window, sign out and use **Dev sign-in** → "A new person" → a name like **Mira**. She lands on an empty list with **Run your own campaign**: ask for "Fresh Colony". In your window, **Site admin** → **Approve**.
   - Mira: open Fresh Colony. **Mainland** says "No maps yet. Add your Mainland by uploading its art." **Explore** shows only the dashed starter area and "Nothing charted yet." Nothing from Sample Colony and no Eldari anywhere, the **Colony** board included: with the window wide, the card with the day dial has no faint art behind it.
   - **Add a map**: name "Eldari", upload your own file (`~/myCodeSpace/party-planner/apps/web/public/Eldari.png`, 3.7 MB, or `~/myCodeSpace/benthedev/apps/colony-planner/web/public/eldari.webp`), leave **Mainland** on. The map opens with your art and no pins. Pin a place after creating one under **Places**. The **Colony** board now shows that art faintly behind the day dial.
   - On its card, turn **Visible to players** off, then turn **View as player** on: the board's faint art is gone (players never get a hidden Mainland). Turn both back.
   - This is the path you'll use for your own campaign: Eldari is uploaded like any DM's art.
10. **5,000 hexes.** **This erases your local data again.** Press Control-C in the dev tab, then:

    ```bash
    mise run reset
    mise run seed -- --hexes 5000
    mise run dev:phone
    ```

    - On the Mac (as Ana or the DM), **Explore** says "5,000 hexes charted." **Fit**, then pan and zoom around: it stays smooth. Labels "Survey mark 1" to "Survey mark 49" appear as you zoom in.
    - On the phone, the same: one finger pans and pinch zooms smoothly in Look mode, from fully zoomed out to zoomed in. In Paint mode, a one-finger stroke still follows your finger.
    - Run `mise run fresh` afterwards to get the normal sample data back.
11. **Install the site.** In Chrome on the Mac, open http://localhost:5173: the address bar shows an install icon (a screen with a down arrow), or the ⋮ menu offers **Cast, save and share → Install page as app…** / **Install Colony Planner…**. Install it: it opens in its own window with the Colony Planner icon. (Installing on a phone needs HTTPS, so that's checked in M6.) You can uninstall it from that window's ⋮ menu.
12. **Campaigns stay apart.** Sign in as **Hollis** and open Second Sample (his campaign): **Explore** shows its own 7 hexes (**Ridgehold**, **The Old Mine**), and **Mainland** has no maps. Nothing from Sample Colony.
13. **Checks.** In a second Terminal tab, run `mise run check`. It ends with "All checks passed" after a few minutes. The secrecy sweep now plants a hidden map with its own art, a pin of a hidden place on a visible map, a visible place pinned on a hidden map, a hidden NPC's portrait and an unused upload in both sample campaigns, and checks that no other player, outsider or other campaign's DM ever sees them, and that every hidden image answers exactly like a missing one.

## When you're done

- Press Control-C in the `mise run dev` tab. `mise run db:down` stops Postgres; your data is kept.
